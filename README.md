# Aquarium Koi

A bright pixel-art aquarium theme for Claude Code in the Claude desktop app (and mobile).
The whole window becomes a sunlit reef with a Japanese garden feel: koi carp (kohaku,
sanke, showa, ogon, tancho, yamabuki), sea turtles, clownfish, tangs, an angelfish, neon
tetras and jellyfish, a red torii gate, two glowing stone lanterns, a pagoda and a sunken
ship in the distance, lotus pads at the surface, drifting cherry blossom petals, corals,
light rays and rising bubbles.

## Life in the tank

- **Feeding time** every 75 seconds: food falls and a tancho koi swims over to eat it.
- **Click the water**: the water shader answers with a ripple, plus caustic sparkles near
  the surface and a soft light under the pointer.

## Look

Pixel-framed message bubbles in koi orange, lagoon teal, gold and coral pink; Claude's
replies sit in a deep-water panel with a turquoise frame. Dark mode only. With Reduce
Motion the aquarium shows as a finished still picture. The terminal draws no theme.

Scene: `hooks/scene.ts`, generated by `generate_scene.py`. Shader: `hooks/water.ts`.

## Install

At the prompt of a terminal session:

```
/plugin install aquarium-koi --marketplace plusjamaisaterre/aquarium-koi
```

Answer `y` to add the marketplace, then pick a scope (user, for every session).

From a shell:

```bash
claude plugin install aquarium-koi --marketplace plusjamaisaterre/aquarium-koi
```

The repository is private: GitHub must be set up on the computer that installs it.
